# Guide des Métiers de l’Electrotechnique · 1.4.0

Extraire **tout** le dossier du ZIP, puis ouvrir **Guide-Electrotechnique.exe**. Garder le dossier `app` à côté de l’EXE. Le lanceur utilise .NET Framework fourni avec Windows 10/11 et ouvre un navigateur moderne sur `http://127.0.0.1:8876/`. Aucun Python, Node, Java ou Flash à installer pour utiliser le guide.

Le serveur écoute seulement sur cet ordinateur. Pour l’arrêter, utiliser l’icône du guide dans la zone de notification puis **Quitter**. Une seconde ouverture réutilise le serveur existant.

Dans **Préférences**, choisir Français / English / العربية, Clair / Sombre, la taille de lecture et les animations réduites. **Simulations du guide** ouvre les 41 activités reconstruites. **Laboratoire interactif** propose sept expériences supplémentaires. **Parcours de progression** contient les 36 leçons et leurs quiz. **Évaluation pratique** propose une session de 12 questions variables.

Le guide conserve 615 entrées, 89 chapitres, 7 domaines, 769 SWF originaux et huit PDF. Les favoris et résultats sont enregistrés localement par navigateur. Ctrl+K ouvre la recherche. Les documents originaux restent accessibles.

Quatre références n’avaient pas de fichier dans la source : S1/S133/Ctn01.swf (deux entrées), S2/S243/Act01.swf et S3/S312/Sch05.swf. Deux autres fichiers, S3/S352/Ccs22.swf et Ccs31.swf, sont illisibles ; leurs alternatives pédagogiques sont signalées.

Lire **NOUVEAUTES-1.4.0.md** pour les changements, les sources et les limites des traductions. **VERIFICATION.md** distingue les tests programmatiques de la validation visuelle et sur téléphone non réalisée.
